// Exercício 1: Crie um programa que receba uma palavra e informe se ela é um palíndromo. Uma palavra é palíndromo quando pode ser lida da mesma forma da esquerda para a direita e da direita para a esquerda.

bool ehPalindromo(String palavra) {
  int inicio = 0;
  int fim = palavra.length - 1;

  while (inicio < fim) {
    if (palavra[inicio] != palavra[fim]) {
      return false;
    }
    inicio++;
    fim--;
  }

  return true;
}

void main() {
  String palavra = 'arara';

  if (ehPalindromo(palavra)) {
    print('É um palíndromo');
  } else {
    print('Não é um palíndromo');
  }
}

// Exercício 5: Escreva um programa que receba uma lista de nomes e retorne uma nova lista ordenada em ordem alfabética.

List<String> ordenarNomes(List<String> nomes) {
  List<String> copia = [];

  for (var nome in nomes) {
    copia.add(nome);
  }

  for (int i = 0; i < copia.length - 1; i++) {
    for (int j = 0; j < copia.length - 1 - i; j++) {
      if (maiorQue(copia[j], copia[j + 1])) {
        String temp = copia[j];
        copia[j] = copia[j + 1];
        copia[j + 1] = temp;
      }
    }
  }

  return copia;
}

bool maiorQue(String a, String b) {
  int tamanho = a.length < b.length ? a.length : b.length;

  for (int i = 0; i < tamanho; i++) {
    int ca = a.codeUnitAt(i);
    int cb = b.codeUnitAt(i);

    if (ca > cb) return true;
    if (ca < cb) return false;
  }

  return a.length > b.length;
}

void main() {
  List<String> nomes = ['Pedro', 'Ana', 'Lucas', 'Mariana', 'João'];

  print(ordenarNomes(nomes));
}

Map<String, int> contarPalavras(List<String> palavras) {
  Map<String, int> contagem = {};

  for (var palavra in palavras) {
    if (contagem.containsKey(palavra)) {
      contagem[palavra] = contagem[palavra]! + 1;
    } else {
      contagem[palavra] = 1;
    }
  }

  return contagem;
}

    'maçã',

    'laranja',
    'maçã',
    'banana'
  ];

  Map<String, int> resultado = contarPalavras(palavras);

  print(resultado);
}

int fatorial(int num){
  int fat = 1;
  if (num == 0 || num == 1) return fat;
  else{
    for (var i = 1; i <= num; i++){
      fat *= i;
    }
  }
  return fat;
}

}

/* Exercício 1: Crie uma função chamada calcularMMC que receba dois números inteiros representando denominadores de frações e retorne o menor múltiplo comum entre eles. Essa função será útil em situações nas quais precisamos somar ou comparar frações com denominadores diferentes.

A função deve:

-receber dois parâmetros inteiros;
-não aceitar denominadores iguais a zero;
-funcionar corretamente mesmo quando os valores -recebidos forem negativos;
-retornar sempre um número inteiro positivo;
-usar uma estratégia baseada no cálculo do MDC ou outra abordagem matematicamente correta.*/

int calcularMDC(int a, int b) {
  if (a < 0) a = -a;
  if (b < 0) b = -b;

  while (b != 0) {
    int resto = a % b;
    a = b;
    b = resto;
  }

  return a;
}

int calcularMMC(int a, int b) {
  if (a == 0 || b == 0) {
    throw ArgumentError('Denominadores não podem ser zero');
  }

  int mdc = calcularMDC(a, b);
  int mmc = (a * b) ~/ mdc;

  // garante que o resultado seja positivo
  if (mmc < 0) mmc = -mmc;

  return mmc;
}

}

/*Exercício 2: Crie uma classe chamada Fracao com os atributos numerador e denominador. A classe deve representar uma fração matemática e permitir a soma entre duas frações usando o MMC dos denominadores.

Atenção às regras de soma de frações: quando os denominadores são iguais, conserva-se o denominador e somam-se apenas os numeradores. Quando os denominadores são diferentes, é necessário encontrar um denominador comum, normalmente usando o MMC, antes de somar as frações.

A classe deve:

possuir um construtor que receba numerador e denominador;
não permitir que o denominador seja zero;
ter um método chamado somar que receba outra Fracao como parâmetro;
usar o MMC dos denominadores para calcular a soma corretamente;
retornar uma nova Fracao como resultado da soma;
ter um método para exibir a fração no formato numerador/denominador.*/

class Fracao {
  int numerador;
  int denominador;

  Fracao(this.numerador, this.denominador) {
    if (denominador == 0) {
      throw ArgumentError('Denominador não pode ser zero');
    }
  }

  int calcularMDC(int a, int b) {
    if (a < 0) a = -a;
    if (b < 0) b = -b;

    while (b != 0) {
      int resto = a % b;
      a = b;
      b = resto;
    }

    return a;
  }

  int calcularMMC(int a, int b) {
    int mdc = calcularMDC(a, b);
    int mmc = (a * b) ~/ mdc;

    if (mmc < 0) mmc = -mmc;

    return mmc;
  }

  Fracao somar(Fracao outra) {
    int mmc = calcularMMC(this.denominador, outra.denominador);

    int novoNumerador =
        (this.numerador * (mmc ~/ this.denominador)) +
        (outra.numerador * (mmc ~/ outra.denominador));

    return Fracao(novoNumerador, mmc);
  }

  void exibir() {
    print('$numerador/$denominador');
  }
}

void main() {
  Fracao f1 = Fracao(1, 2);
  Fracao f2 = Fracao(1, 3);

  Fracao resultado = f1.somar(f2);

  resultado.exibir(); // 5/6
}

/* Exercício 3: Crie uma função chamada calcularSimilaridadeCosseno que receba dois vetores numéricos representados por listas de double e retorne a similaridade entre eles usando a fórmula da similaridade do cosseno.

Esse tipo de cálculo é muito usado em aplicações modernas de Inteligência Artificial, especialmente em sistemas de recomendação, busca semântica, comparação de textos por embeddings e recuperação de informações. A ideia é comparar a direção de dois vetores, e não apenas a distância direta entre eles.

A fórmula da similaridade do cosseno é:

similaridade = produtoEscalar(vetorA, vetorB) / (modulo(vetorA) * modulo(vetorB))
A função deve:

receber duas listas de double;
verificar se as duas listas possuem o mesmo tamanho;
lançar uma exceção caso os vetores tenham tamanhos diferentes;
calcular o produto escalar entre os dois vetores;
calcular o módulo de cada vetor;
retornar um valor double representando a similaridade;
tratar o caso em que algum vetor tenha módulo igual a zero.*/

double raiz(double x) {
  double r = x;

  for (int i = 0; i < 10; i++) {
    r = (r + x / r) / 2;
  }

  return r;
}

double calcularSimilaridadeCosseno(List<double> a, List<double> b) {
  if (a.length != b.length) {
    throw ArgumentError('Vetores devem ter o mesmo tamanho');
  }

  double produto = 0;
  double somaA = 0;
  double somaB = 0;

    somaA += a[i] * a[i];
    somaB += b[i] * b[i];

  double moduloB = raiz(somaB);

  if (moduloA == 0 || moduloB == 0) {
    throw ArgumentError('Vetor com módulo zero');
  }

  return produto / (moduloA * moduloB);
}

MSE = soma((valorReal - valorPrevisto)^2) / quantidadeDeValores

receber duas listas de double;
verificar se as duas listas possuem o mesmo tamanho;
lançar uma exceção caso as listas tenham tamanhos diferentes;

double calcularErroMedioQuadratico(List<double> reais, List<double> previstos) {

    (item) =>
      typeof item.nome === "string" &&
      typeof item.quantidade === "number" &&
      typeof item.precoUnitario === "number" &&
      item.quantidade > 0 &&
      item.precoUnitario > 0
  );

  if (!itensValidos) {
    throw new HttpsError(
      "invalid-argument",
      "Cada item deve ter nome, quantidade e precoUnitario válidos."
    );
  }

  const itensCalculados = itens.map((item) => ({
    ...item,
    subtotal: parseFloat((item.quantidade * item.precoUnitario).toFixed(2)),
  }));

  const valorTotal = parseFloat(
    itensCalculados
      .reduce((acc, item) => acc + item.subtotal, 0)
      .toFixed(2)
  );

  const pedido = {
    usuarioId: request.auth.uid,
    itens: itensCalculados,
    valorTotal,
    status: "pendente",
    criadoEm: new Date().toISOString(),
  };

  const docRef = await db.collection("pedidos").add(pedido);

  return {
    sucesso: true,
    pedidoId: docRef.id,
    valorTotal,
    mensagem: "Pedido criado com sucesso!",
  };
});
