1. Backend — Cloud Functions, TypeScript e Balcão P2P

TópicoResumo
passwordReset.ts — types e regionAliases SendResponse, VerifyResponse, ConfirmResponse documentam o contrato de cada etapa em compile-time (não existem em runtime). region: "us-central1" deve coincidir com FirebaseFunctions.instanceFor(region: ...) no Flutter.
email?: string: separa nome e tipo; ? torna o parâmetro opcional (undefined). Validação com if (!email) é a defesa real em runtime.
VerifyResetCodeResult= define alias de tipo; | une variantes (discriminated union com ok: true/false). Quebra de linha com | à esquerda é só estilo.
Math.max(0, ...)Ao liberar escrow, impede saldo bloqueado negativo se dados estiverem desalinhados.
1e-9Epsilon nas comparações de saldo — tolerância a imprecisão de float IEEE 754; não é “desconto” financeiro.
{ merge: true }set mescla campos sem apagar o resto do documento; essencial ao atualizar só tokensLockedInOrders ou brlLockedInOrders.
EscrowReserva temporária: compras bloqueiam BRL (brlLockedInOrders), vendas bloqueiam tokens (tokensLockedInOrders). Disponível = saldo − locked.
trx em runTransactionAbreviação de transaction — leituras/escritas atômicas; ou commita tudo ou nada, com retry em conflito.
outer: / break outerLabel JS/TS para sair de dois for aninhados no match engine após um par executado.
Record<string, unknown>Objeto indexado por string com valores a tipar; meio-termo entre any e interface fixa ao ler Firestore.
request.data?.actionCampo que roteia callables (simulateWallet, passwordReset, twoFactor). ?.` optional chaining. Distinto de ledger.op.
assertPositiveIntegerTokensGarante tokens inteiros > 0 ou lança HttpsError — tokens não são fracionáveis no modelo.
assert (funções vs testes)Prefixo assert* = validação que lança HttpsError; node:assert nos testes verifica expectativas.
clip(s, max)Sanitiza strings (trim + limite de caracteres) sem lançar erro — diferente das funções assert*.

10. Mapa conceptual — como as peças se ligam

O MesclaInvest combina Flutter (UI reactiva com StreamBuilder, FutureBuilder, tema Material 3 customizado) com Firebase (Auth, Firestore, Cloud Functions em TypeScript). O módulo Balcão usa transações Firestore, escrow e match engine para P2P simulado. Padrões recorrentes: validação defensiva (assert*, is/as), sanitização (clip), callbacks para desacoplamento (onInvestir), singletons de cache, e proteção async (mounted, addPostFrameCallback).
