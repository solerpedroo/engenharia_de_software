#### ***Redes***



* Modelo OSI --> Pilha de protocolos (protocolo = conjunto de regras)



* Na pilha tem sete camadas --> sétima camada, protocolos: HTTP, SSH, FTP



* A primeira camada é a física (princípio de tudo), especifica como o computador de rede vai se conectar com outro (cabo, drivers...)



* Segunda camada é a enlace -- como o computador chega a outro



* Camada três -- transporte, usa o protocolo TCP (protocolo de transporte e comunição)



* Camada quatro -- IP (endereçamento), DHCP (distribui um unico numero de IP para cada computador)



* O que é um servidor? É um computador capaz e destinado a fazer coisas pelos clientes, processa requisições e possui / presta alguns tipos de serviços 



* Arquitetura cliente-servirdor, um computador é o servidor e pode ter N clientes



* Request ------> 

&nbsp;  (cliente para o servidor)



* Response <-------

&nbsp;  (servidor para o cliente)



* GET ---> buscar a informação no servidor 



* POST ---> quando vai deixar a informação no servidor
